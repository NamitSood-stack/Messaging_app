Features

Everything a chat app needs

The core of a modern messenger, built from scratch: accounts, live delivery, history and a layout that adapts to any screen.

Instant delivery

A live WebSocket connection pushes every message to the other person immediately, on every tab and device they have open.

Secure accounts

Passwords are hashed with scrypt and never stored as plain text. Sessions use httpOnly cookies that scripts on the page can't read.

Find people fast

Search for any user by username and open a private conversation in one click. Each pair of users gets exactly one chat.

Reliable sending

Messages appear the moment you send them. If the network drops, tap to retry. The server recognises repeats, so a retry never creates a duplicate.

Full history

Scroll up to load older messages, 50 at a time. Your chats are also saved in the browser, so they appear instantly after a reload.

Any screen

Two panels on a laptop, one at a time on a phone. The layout adapts to whatever device you're using.

How it works

From sign up to first message in a minute

Three steps from opening the page to your first conversation.

  1. 1

    Create an account

    Pick a username and a password. That's all. No email or phone number required.

  2. 2

    Find someone

    Type a friend's username in the search box. Their profile shows up as you type.

  3. 3

    Start chatting

    Send a message and it arrives right away. Your chat list keeps track of new and unread messages.

Under the hood

Simple stack, real-time core

The browser talks to a Node.js server in two ways. A REST API handles accounts, the chat list and loading history. A WebSocket connection, managed by Socket.IO, carries live messages in both directions.

When you send a message, the server checks that you belong to that chat, stores it, and pushes it to both people at once. Every user has their own delivery channel, so a message reaches all of their open tabs and devices.

FAQ

Frequently asked questions

Do I need to install anything?

No. Chat runs entirely in your web browser, on any operating system.

Can other people read my conversations?

No. The server only lets the two members of a chat load or send messages in it. Logging out also clears the saved copy from that browser.

Does it work on my phone?

Yes. On a small screen the layout switches to one panel at a time, just like a mobile app.

Why did my account disappear?

This version keeps data in the server's memory, so a server restart clears it. Permanent storage with PostgreSQL is the next planned step.
